# Smart Library QR System

A simple browser-based library management page for issuing and returning books using a QR code for quick identification.

## Features
- Capture student name, roll number, book ID, and book name
- Issue books to students and save the record locally in the browser
- Generate a QR code for the issued book
- Return books using the roll number and book ID
- View the list of issued books on the page

## Run locally
1. Open `index.html` in a browser, or
2. From the project folder, run a local static server:
   `python -m http.server 8000`
3. Visit `http://localhost:8000`
